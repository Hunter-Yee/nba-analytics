Project: production-style NBA Live Analytics Platform focused on historical game replay and win probability modeling.  
The initial version should focus ONLY on historical NBA games (likely 1990s onward) using play-by-play data. Users should be able to select a historical game, press play, and watch the game replay possession-by-possession while a live-updating win probability graph changes dynamically over time based on model predictions. The platform should display score, quarter, time remaining, possession, momentum swings, and probability trends in an interactive dashboard.
